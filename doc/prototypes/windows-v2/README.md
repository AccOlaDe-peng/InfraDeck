## 统一设计约束

- 全局动作仅放标题栏；当前视图动作紧贴当前内容。
- 连接管理栏与 AI/活动栏可拖拽调整宽度。
- 状态与分类使用颜色，普通功能不依赖装饰色。
- 高风险操作在 AI 对话流内确认，不使用打断式模态框。
- 表格与终端优先保证信息密度；主页和空状态保留适量留白。
- 文件传输采用本地/远程双栏模型，两栏和底部队列均可拖拽缩放；文件拖入目标目录或空白区域即开始传输，默认界面不常驻展示拖放提示。
- Windows 只显示一套窗口控制按钮，不显示应用 Logo 和标题。

## 高密度尺寸基线

- 顶栏约 36px，普通操作文字 10–11px，次要文字 9px。
- 左侧连接栏默认约 190px，右侧 AI 栏默认约 300px，均允许拖拽。
- Tab 约 30px，按钮 24–28px，表格行约 26px。
- 常规 padding 与 margin 比首版缩减约 30–40%。
- 底部状态栏 18–20px，状态文字 9px。
- 收缩所得空间全部让给中间主工作区。
